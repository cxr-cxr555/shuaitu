# 率土抽卡收益计算器

按武将分值分别计算卡包的小保底、大保底平均分，并按收益从高到低排名。

## 本地运行

需要 Node.js 18 或更高版本。

```powershell
npm run dev
```

浏览器打开 `http://127.0.0.1:4173`。

运行自动测试：

```powershell
npm test
```

## 首版规则

- 武将分值固定为 1–4 分：1 无用、2 能加红、3 有用、4 刚需。
- 同一武将在所有卡包和赛季共用一个分值。
- 平均分公式为：已评分武将分值之和 ÷ 已评分武将人数。
- 未评分武将不参与计算，榜单显示“已评分 x/y”。
- 同一武将不能同时进入同一卡包的大小保底名单。
- 默认预置常规卡包：东吴、魏晋、蜀汉、群雄。
- 默认预置赛季卡包：征服 1–4、割据 1–2。
- 已录入修正后的 133 个五星卡面记录。
- 同名不同阵营的卡面在名称前加阵营，例如“晋司马懿”“魏关羽”。

## 数据与隐私

武将、卡包、分值和本地立绘全部保存在浏览器的 IndexedDB 中。网页不上传任何数据，也没有后端服务。

同一永久链接在不同浏览器、不同设备上的数据彼此独立。清理浏览器站点数据会删除已录入内容。

## 发布永久链接

仓库包含 `.github/workflows/pages.yml`。把项目推送到 GitHub 仓库的 `main` 分支后：

1. 打开仓库 `Settings` → `Pages`。
2. 在 `Build and deployment` 中选择 `GitHub Actions`。
3. 等待 `Deploy static site to GitHub Pages` 工作流完成。
4. 在 Pages 设置页或 Actions 部署结果中获取永久网址。

也可以将项目作为纯静态站点部署到 Cloudflare Pages、Netlify 或任意静态文件服务器，发布目录就是项目根目录，不需要构建命令。
